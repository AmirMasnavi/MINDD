# Shared working rules

- Read ../README.md, project.md, and MEMORY.md before starting; use REQUIREMENTS.md
  for the assignment and PLAN.md for the next work item.
- Task 1 implementation is authorised. Work in small, explained steps and justify
  decisions with observed evidence. Do not begin classifier modelling before Task 1 is complete.
- Keep the original PDF and CSV unchanged. Use exact CSV field names and relative paths.
- Never invent target mappings, measured findings, due dates, or instructor requirements.
  Distinguish PDF requirements, observed facts, and team proposals.
- Enforce prediction-time availability and the training-only preparation policy in PLAN.md.
- Keep work minimal: add a file, dependency, transformation, or figure only when it
  solves a demonstrated need. Avoid duplicate documentation and unnecessary frameworks.
- Agree notebook ownership before editing; keep changes focused and reviewable.
- After meaningful work, update PLAN.md status and MEMORY.md with dated outcomes,
  decisions and reasons, blockers, evidence locations, and the next action.
- Store durable working rules here; changing facts/status belong in MEMORY.md.
  Do not store raw user identifiers, credentials, or full data samples in documentation.
